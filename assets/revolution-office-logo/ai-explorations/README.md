# Higgsfield explorations

Raster renders from Higgsfield (Nano Banana Pro, 2k) prompted with the vector
master as the image reference. Kept only the four that came out clean; two more
(all-black, white-on-orange) ghosted or swapped the typeface and were discarded,
and the AI background remover hollowed out the flat letterforms, so transparent
versions here come from the vector files instead.

| File | Notes |
|---|---|
| `higgsfield_00-original-white.png` | Faithful colours; REVOLUTION rendered in a condensed face rather than Montserrat |
| `higgsfield_01-navy-orange.png` | Clean, closest to the vector master |
| `higgsfield_02-orange-white-on-dark.png` | Clean, on `#141414` |
| `higgsfield_05-icon-only.png` | Clean icon mark, 2048 px square |

Use the SVG / PNG files in the parent folders for anything going to print or
web; these are for comparison and mood only.
