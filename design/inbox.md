# Inbox

Drop URLs here whenever you see something worth keeping. One per line. That's the whole gesture —
no form, no app, no server. Editable from a phone via the GitHub app if that's where you are.

Optional: add `| why you saved it` after the URL. It gets folded into the reference entry, and it's
worth 5 seconds now because it's the part you won't remember later.

Then run `/design-ingest` and the queue gets processed into `design/references.md` +
`design/tokens/`, and cleared. Batch of 1 or batch of 40 — same command.

Lines starting with `#` are ignored.

```
# examples of the two accepted forms:
# https://example.com
# https://example.com | the way the nav collapses on scroll
```
