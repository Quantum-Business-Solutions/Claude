# SOW Client Interview Guide

Use these questions to gather the information needed to build a complete SOW.
Ask in conversational rounds — never dump all questions at once.

---

## Universal Questions (All Project Types)

| # | Question | Why It Matters |
|---|---|---|
| 1 | Client company name (legal name) | Appears in SOW header and throughout |
| 2 | Client primary point of contact name & title | Responsibilities section |
| 3 | Quantum point of contact / account manager | Internal reference |
| 4 | Anticipated project start / kickoff date | Timeline section |
| 5 | Fixed project fee (from the accepted quote) | Fees section |
| 6 | Any special terms negotiated? | Scope or pricing exceptions |
| 7 | Is there an existing MSA in place? | SOW header reference |

## Red Flag Questions (Ask When Something Feels Unclear)

These questions protect Quantum. Ask them if the project feels complex or ambiguous:

- "Are there any customizations the client has already requested that we've verbally agreed to?"
- "Is there a data migration component? How many records and from how many sources?"
- "Does the client have a dedicated internal champion who can make decisions?"
- "Have there been any prior failed implementations we should be aware of?"
- "Is the client bringing their own HubSpot portal or starting fresh?"
- "Are there regulatory or compliance requirements we need to account for?"
